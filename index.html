Style Guide
Text formatting
**bold**Bold text
*italic*Italic text
~~strike~~Strikethrough
==highlight==Highlighted text — same syntax Obsidian uses, so vaults stay portable both ways. Nests with other formatting: ==**bold** highlighted==
<span style="color:#e05a5a">red</span>Coloured text — raw HTML, any CSS colour works. Same for backgrounds: style="background:#333"
<u>underline</u>Underline — not standard markdown, but raw HTML like this passes through and renders fine
`inline code`Inline code
> quoted textBlockquote
Headings & structure
# H1Heading, levels 1–6 (# through ######). Shows up in the Outline popover (☰ button in the editor header).
---Horizontal rule. On its own line, this is ALSO the slide-divider when exporting a note as a presentation.
Lists & tasks
- itemBullet list (also * or +)
1. itemNumbered list
- [ ] todoTask checkbox, unchecked
- [x] doneTask checkbox, checked
Click a checkbox in the rendered preview to toggle it — updates the [ ]/[x] in the note directly, no need to edit the raw text. Checked tasks show with a strikethrough.
Tables
| A | B | |---|---| | 1 | 2 |Standard GFM table. Add :---/---:/:---: in the divider row to align a column left/right/center.
Callouts
> [!note] > textStyled callout box. Swap note for tip, info, warning, caution, danger, or important for a different icon/color.
Code
```javascript code here ```Fenced code block. Name a language (javascript, python, bash, json, css, html, sql, yaml, cpp, csharp, java, typescript, markdown, …) to get syntax highlighting — leave it off for plain monospace, no auto-guessing.
Typing a third backtick in the editor auto-expands into an empty fenced block for you.
Text alignment
<div align="center"> text </div>Center (or left/right) a block of text. Markdown has no native alignment syntax — this is raw HTML, the standard fallback — reachable from the toolbar's Align ▾ dropdown so you don't have to type it by hand.
Links between notes
[[Note Title]]Link to another note by title. Click a broken one to create it on the spot.
[[Note Title#Heading]]Link to a specific heading inside another note
[[Note Title|shown text]]Link with custom display text
![[Note Title#Heading]]Transclusion — embeds that section's content inline. Requires a heading (no bare ![[Note]]). Expands exactly one level deep, even if the embedded section itself contains another transclusion.
[normal link](url)Ordinary markdown link, works for external URLs same as any markdown
![alt](image.png)Image — drag-and-drop or paste an image into the editor to insert one automatically
Properties (frontmatter)
Open the Properties tab in the note footer — a raw YAML box for anything beyond title/tags/folder.
type: characterAny custom field. Entity templates (toolbar → Insert ▾ → Template) prefill a matching set for character/faction/place/event/chapter/plan/note.
aliases: [Vess, Warden]Alternate names — [[Vess]] resolves to this note too
enemy_of: "[[Other Note]]"Typed relationship — MUST be quoted. Unquoted [[...]] is valid YAML shorthand for a nested list, not a link, and won't work as one.
Query blocks — live lists from your notes
```query type: character sort: date ```Matches notes by property (key: value), renders as a table. Empty block matches every note.
tag: pov tag: wardenRepeated tag: lines are AND — note must have ALL listed tags
type: character type: factionRepeated PROPERTY lines (same key) are OR — matches either value
links-to: [[Note]]Only notes that link to the given note
sort: -dateSort descending (leading -); omit it to sort ascending
limit: 10Cap the result count
Task rollup
```tasks tag: chapter done: false ```Same clauses as a query block (tag/property/links-to/sort/limit), plus done: true/done: false — collects every - [ ]/- [x] from matching notes, grouped by source note.
Tags
Set in the Tags field in the note footer, comma-separated. Click tags in the sidebar to filter — click more than one to narrow to notes with ALL of them. Use the search box above the tag list to find a tag in a large vault.
